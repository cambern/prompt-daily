Prompt Daily — Privacy Policy

Effective date: October 26, 2026 · Last updated: November 8, 2026 · Applies to version 1.0.0 and later · Contact: nerbmac@163.com

中文版 / Chinese version: privacy.html · Both versions describe the same practices.

In one sentence: this extension has no server. Your prompts, tags, drafts and usage counts live in your own browser, on your own computer. The developer cannot access them, does not want them, and never receives them. The only outbound request is made when you turn on WebDAV sync yourself, and that data travels from your browser directly to the WebDAV server you configured.

1. What data this extension handles

Strictly speaking, this extension collects no data for or to the developer. The three categories below are information processed on your own device. Each is described separately.

1.1 Prompts and related records

  • What: prompt title, body text, tags, favorite flag, creation and modification timestamps, usage count, and deleted items kept in Trash
  • Where: chrome.storage.local on your device
  • Why: to display the list, search, sort, and copy or insert a prompt when you use it
  • Whether it leaves your device: not by default. Only if you enable WebDAV sync is it written, together with sync metadata, to the server you configured yourself

1.2 WebDAV connection credentials

  • What: server URL, username, password, and optionally a remote file path
  • Where: chrome.storage.local, stored in plain text inside the extension storage area, subject to the same security boundary as the browser's own storage
  • Why: HTTP Basic authentication when sending requests to the WebDAV server you entered
  • Whether it is sent to the developer: no. The developer does not hold, relay, or log these credentials

1.3 Text you explicitly select on a web page

  • What: the passage you select when you use the context menu item "Save as Prompt"
  • How it is handled: read once, only when you trigger the action, and stored as the body of that prompt. From then on it is treated exactly like text you typed yourself
  • Whether it scans pages: no. The extension does not read or upload anything else on the page. The in-page panel renders only its own interface and does not parse conversation content

1.4 What we do not collect

  • No accounts, and no collection of names, email addresses or phone numbers
  • No analytics, no crash reporting, no usage statistics, no advertising SDKs
  • No reading of your browsing history, and no logging of the pages you visit
  • No reading of clipboard history. The extension writes to the clipboard once, when you click Copy
  • No location data and no device identifiers

2. How data is transmitted and stored

ScenarioData flowTransport
Everyday use (create, edit, copy, insert)Local browser storage ↔ extension UI; stays on the deviceNo network request
WebDAV sync enabledYour browser → the WebDAV server you configuredHTTPS to the address you provided, or HTTP if you configured it that way
Developer sideDoes not existThe developer has no server and no API

The extension makes no request to any developer-controlled endpoint. Sync is strictly user-to-user-server.

3. Data retention and deletion

  • How long: until you delete it. The extension never automatically uploads or archives anything to a remote server
  • Deleting a single item: it moves to Recently Deleted (Trash), where it is kept for 90 days and then removed automatically. You can also click Empty immediately to delete it permanently
  • Deleting everything: Settings → Data lets you export the whole library as JSON or clear it. Uninstalling the extension deletes all local data with it
  • Remote copies on WebDAV: managed by you on that server. This extension does not delete remote files on your behalf
  • Deletion requests: because the developer holds no data, there is nothing to request. If you still need help, you can use the email below

4. Whether data is shared with third parties

No sharing, no selling, no transfer. There is no third-party SDK, no analytics, no CDN script. All code runs inside the extension package and no remote code is loaded.

The only path that can reach a third party is the WebDAV provider you configure yourself, for example Nutstore, Nextcloud, Synology or Alist. Whether your data passes through it and how it is retained there are governed by your agreement with that provider and lie outside this extension's control.

6. Your controls

  • Turn off "insert after click", turn off the panel master switch, or disable the panel per site, at any time in Settings
  • Revoke granted site permissions at any time in the browser's extension management page
  • Export the whole library as JSON, or clear all data, at any time
  • Uninstall the extension if you no longer want it; local data is deleted with it

7. Children

This extension is not directed to children under 13 and does not knowingly process personal information from children.

8. Changes to this policy

If the way data is handled changes materially, for example if any form of cloud service is introduced in the future, this page will be updated and the effective date at the top revised. If the scope of collection changes, the change will also be called out in the extension's release notes. Continued use constitutes acceptance of the updated policy.

9. Consistency with Chrome Web Store disclosures

In the Chrome Web Store "Privacy practices" section, this extension declares two data categories: Authentication information, referring solely to the WebDAV credentials described in section 1.2, and Website content, referring solely to the passage you deliberately select on a page and save through the "Save as Prompt" context menu, as described in section 1.3. The extension reads nothing else on the page, and never uploads or analyses any web content. It also makes the following commitments: user data is not sold; it is not used for purposes unrelated to the extension's single purpose; it is not used to determine creditworthiness or for lending purposes. This page is consistent with that disclosure and with the extension's actual behaviour.

10. Contact

For any question, concern or data-related request about this policy, please contact nerbmac@163.com. We normally reply within 7 business days.
