Prompt Daily·每日魔咒 浏览器里的 Prompt 收藏夹

把常用的 Prompt 攒起来，点一下就用

同一段提示词，一天要复制三遍。存在备忘录里，找起来要翻；存在聊天记录里，改一次要重贴。Prompt Daily 把它们收进一个随叫随到的抽屉——在 ChatGPT、Claude、Gemini、DeepSeek、Kimi、通义、豆包等 18 个 AI 站点的页面右侧，常驻一颗悬浮球。

A local-first prompt manager for your browser. No account, no server, no analytics. The interface is in Chinese.

能做什么

一键取用点卡片即复制；开着「填入输入框」时，直接写进当前站点的对话框。
标签整理每个 Prompt 可打多个标签，按使用频次自动排序，常用的总在手边。
模板变量正文写 {{主题}} {{语气}}，取用时填个小表单，复制到的是填好的成品。
批量整理勾选后批量打标签、导出、删除；删掉的先进回收站，随时恢复。
网页浮窗在 AI 对话页右侧常驻悬浮球，可拖到任意位置；也能在任何网站上手动开启。
多设备同步可选 WebDAV（坚果云 / Nextcloud / 群晖等），单文件增量合并。

数据在哪里

所有 Prompt、标签、草稿、使用次数都存在你自己电脑的浏览器里。

开发者不运营任何服务器，不接收、不上传、不分析你的内容。没有账号体系，没有埋点，没有广告。唯一的出网请求发生在你亲手开启 WebDAV 同步之后，且只发往你自己填写的服务器。
