Privacy Policy

生效日期：2026 年 10 月 26 日 · 适用版本：1.0.0 及以后 · 联系方式： nerbmac@163.com

一句话结论：这个扩展没有服务器。你的 Prompt、标签、草稿、使用次数全部存在你自己电脑的浏览器里；开发者拿不到、看不到、也不想要。唯一的对外网络请求，是你自己开启 WebDAV 同步时，数据从你的浏览器直接写进你自己填写的那个 WebDAV 服务器。

In short: there is no developer-operated backend. Everything you store stays in your own browser's local storage. The only outbound request is to the WebDAV endpoint you configure yourself, if you choose to enable sync.

1. 我们收集哪些数据

严格来说，本扩展不向开发者收集任何数据。以下三类是扩展在你设备上处理的信息，逐项说明：

1.1 你保存的 Prompt 与相关记录

  • 内容：Prompt 标题、正文、标签、收藏状态、创建与更新时间、使用次数、回收站里的删除记录
  • 存放位置：本机 chrome.storage.local（浏览器扩展本地存储）
  • 用途：显示列表、搜索、排序、取用时复制或填入
  • 是否离开设备：默认不离开。仅当你开启 WebDAV 同步时，才会连同同步元数据一起写入你自己配置的服务器

1.2 WebDAV 连接凭据

  • 内容：服务器地址、用户名、密码（以及可选的远端文件路径）
  • 存放位置：本机 chrome.storage.local，明文存储于浏览器扩展存储区（与浏览器自身的存储安全边界一致）
  • 用途：向你填写的 WebDAV 服务器发起请求时的 Basic Auth 认证
  • 是否发给开发者：否。开发者不掌握、不中转、不记录这些凭据

1.3 你在网页上主动选中的文字

  • 内容：你用右键菜单「保存为 Prompt」时选中的那段文字
  • 处理方式：仅在你主动触发时读取一次，存入本条 Prompt 的正文，之后与你手动输入的内容同等对待
  • 是否扫描页面：否。扩展不读取、不上传页面上的其它内容；网页浮窗只渲染自己的界面，不解析对话内容

1.4 我们不收集的

  • 没有账号体系，不收集姓名、邮箱、手机号
  • 没有埋点、没有崩溃上报、没有使用统计、没有广告 SDK
  • 不读取你的浏览历史，不记录你访问了哪些页面
  • 不读取剪贴板历史（只在「复制」动作时向剪贴板写一次）
  • 不收集位置信息、设备标识符

2. 数据如何传输与存储

场景数据流向传输方式
日常使用（新增、编辑、复制、填入）本机浏览器存储 ↔ 扩展界面，不出设备无网络请求
开启 WebDAV 同步你的浏览器 → 你填写的 WebDAV 服务器按你填写的地址使用 HTTPS（或 HTTP，如果你这样配置）
开发者侧不存在开发者没有服务器，也没有接口

The extension makes no request to any developer-controlled endpoint. Sync is strictly user-to-user-server.

3. 数据保留与删除

  • 保留多久：直到你删除为止。扩展不会自动上传或归档任何内容到远端。
  • 删除单条：删除后进入「最近删除」（回收站），保留 90 天后自动清理；也可以立刻点「清空」永久删除。
  • 清空全部：设置页 → 数据，可整库导出或清除；卸载扩展会一并删除本机全部数据。
  • WebDAV 远端副本：由你自己在那个服务器上管理，本扩展不代为删除远端文件。
  • 删除请求：由于开发者不持有任何数据，无需向开发者申请删除；如需协助，仍可通过下方邮箱联系。

4. 是否与第三方共享

不共享、不出售、不转让。没有第三方 SDK、没有 analytics、没有 CDN 脚本，所有代码都在扩展包内运行（不加载任何远程代码）。

唯一可能触达第三方的路径是你自己配置的 WebDAV 服务商（例如坚果云、Nextcloud、群晖、Alist）。数据是否经过它、它如何保存，取决于你与该服务商之间的约定，不属于本扩展的控制范围。

5. 权限与用途对照

权限为什么要它
storage / unlimitedStorage在本机保存 Prompt、标签、设置、草稿与计数；取消配额上限是为了导入历史数据或保存长文时不写入失败
alarms按你设定的间隔（默认 15 分钟）触发 WebDAV 自动同步；不开同步时不会创建任务
contextMenus右键菜单「保存为 Prompt」
scripting在你启用的站点上注入网页浮窗
activeTab点眼睛按钮时判断当前页能否注入浮窗
18 个 AI 站点的主机权限在这些站点上默认显示浮窗；不读取页面内容
可选的任意站点权限你在其它网站上手动开启浮窗时，Chrome 会就该站点单独征求你的同意，一次一站点

6. 你的控制权

  • 随时在设置页关闭「点击后自动填入」、关闭浮窗总开关、逐站点关闭浮窗
  • 随时在浏览器扩展管理页撤销已授予的站点权限
  • 随时导出整库 JSON 备份，或清除全部数据
  • 不想要了直接卸载，本机数据随之删除

7. 儿童

本扩展不面向 13 岁以下儿童，也不会有意处理儿童的个人信息。

8. 政策变更

若数据处理方式发生实质变化（例如未来引入任何形式的云服务），会在本页更新并修改顶部的生效日期；涉及收集范围变化时，还会在扩展的更新说明中明确提示。继续使用即视为接受更新后的政策。

9. 与 Chrome Web Store 数据披露的一致性

在 Chrome Web Store 的「隐私实践」中，本扩展声明的数据类别为 Authentication information（仅指第 1.2 节的 WebDAV 凭据），并作出以下承诺：不出售用户数据；不将数据用于与扩展单一用途无关的目的；不将数据用于信用评估或借贷判定。本页与该披露、以及扩展的实际行为三者一致。

Chrome Web Store Limited Use compliance: data is not sold or transferred to third parties, not used for purposes unrelated to the extension's single purpose, and not used to determine creditworthiness or for lending.
